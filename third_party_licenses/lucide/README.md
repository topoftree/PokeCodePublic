Selected upstream SVG shapes are converted into Android VectorDrawable XML and
Compose ImageVectors. SVG command/arc-flag spacing is normalized for Android
parsers. Rounded strokes and filled dots are preserved; existing
control tint, size and directional mirroring are applied by the app. PokeCode's
conversion tooling and icon mappings are separate from the upstream icon assets.
This notice applies to the icon artwork, not to PokeCode's proprietary source.
