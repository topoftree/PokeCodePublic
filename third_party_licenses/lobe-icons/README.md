# Lobe Icons — Codex mark

PokeCode uses this Codex flower-and-terminal mark beside the Codex heading in
Account settings. The heading supplies its accessible name; Compose supplies
the existing 24dp size and theme tint.

- Source: [Lobe Icons, `packages/static-svg/icons/codex.svg`](https://github.com/lobehub/lobe-icons/blob/82e641b4fece9d1028a127149af9ded00df5ac0c/packages/static-svg/icons/codex.svg).
- Source commit: `82e641b4fece9d1028a127149af9ded00df5ac0c`.
- License: MIT; the complete upstream text is retained in [LICENSE](LICENSE).
- Transformation: preserve the 24 × 24 viewport, original geometry and even-odd fill rule in `app/src/main/res/drawable/ic_codex.xml`. Expand the SVG path's compact arc flags into explicitly separated parameters because Android/Compose's vector parser otherwise misreads them. No library dependency is added.
