# Simple Icons — OpenAI and GitHub marks

PokeCode uses the OpenAI mark beside model names in Usage. The GitHub mark appears
beside the GitHub Repository heading in New project and the GitHub heading in
Account settings. The Codex heading uses the separate [Codex mark](../lobe-icons/README.md).
